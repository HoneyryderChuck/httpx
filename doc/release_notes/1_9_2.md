# 1.9.2

## Improvements

* options: define option setters using cache module unbound methods optimization.
* `:callbacks` plugin: emit an error param in the block for the `:connection_closed` callback (ex: `session.on_connection_closed { |origin, error| } `).
* `:callbacks` plugin: expose the connection object in all the callbacks (`session.on_connection_opened {|_, _, connection: | }`, `session.on_request_started {|request, connection: | }`), allows inspecting connection-specific data.


## Bugfixes

* session: do not checkin a resolver already registered in the selector.
* session: fix receive requests loop handling when an error happens during #fetch_response.
* timers: avoid stale timer intervals delaying session cleanup
* http2: raise error on GOAWAY if the server never handled any streams; this fixes a regression from 1.9.1 which didn't raise an error on GOAWAY and instead allowed unfinished streams to retry transparently; it was also doing that for cases where the peer server would send a GOAWAY without ever processing streams, creating a potential loop. This fix closes the loop if the GOAWAY has a last_stream_id = 0.
* `:cache` plugin: fix regression where error responses weren't being preserved.
* `:callbacks` plugin: only call `:connection_closed` when the connection actually closes (the previous impl didn't guarantee that)
  * To do that, `Connection#disconnect` will return a boolean telling whether it actually disconnected, which simplifies overrides
* `proxy`: implement request accepted callback for the connect proxy parser, so that the connect request sets its request timeouts.
